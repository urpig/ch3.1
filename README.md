## 使用

直接開啟根目錄 index.html，或執行 node server.mjs 後開啟 http://127.0.0.1:4185/electrolytes/index.html 。學習紀錄保存在使用者自己的瀏覽器，無須帳號。

## 建置與測試

需要 Node.js 24，無額外套件。

```sh
node build.mjs
node --test tests/electrolytes/*.test.mjs
```
