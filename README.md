# 第三章｜電解質與酸鹼鹽

小葵與阿公的煉金冒險：皇帝最後的製鹽委託。

公開網站：https://urpig.github.io/ch3.1/ （免登入）

12 張故事卡片、5 個操作實驗、12 題小試身手（每卡 1 題）、138 個科學名詞、學習紀錄與顧問證書。側欄沿用第一章風格，徽章改為鹽山。

## 使用

公開版從根目錄 index.html 載入模組；本機可執行 node server.mjs 後開啟 http://127.0.0.1:4185/electrolytes/index.html 。學習紀錄保存在使用者自己的瀏覽器，無須帳號。

## 建置與測試

需要 Node.js 24，無額外套件。

```sh
node build.mjs
node --test tests/electrolytes/*.test.mjs
```

2026-10-28 互動卡精修版：87 項自動測試通過。模組原始碼在 dist/electrolytes/；共用角色與樣式在 dist/assets/、dist/chemistry/。知識點覆蓋、模型限制與歷次品質檢查見 docs/electrolytes/。

## 2026-10-29 學生操作流程修正

- 舊版完成紀錄會同步還原採樣勾選、微觀比較與驗收紀錄；保留既有作答。

- 每卡顯示尚缺的觀察、預測不計分、實驗後回顧猜想，以及 2–3 句小葵筆記。
